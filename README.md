# Sales Analytics Dashboard

An interactive, production-minded Python Sales Analytics Dashboard built with Streamlit, Pandas, and Plotly.

## Features
- Interactive sales performance metrics (KPIs).
- Time-series revenue trends and category breakdowns.
- Synthetic data generation for testing and custom CSV data uploads.
- Clean, modular Python architecture with automated tests (`pytest`) and linting (`Ruff`).
